# 楷排

楷排是一款面向微信公众号创作者的文章排版工具。导入或粘贴文稿，选择文章风格，调整版式，预览效果后复制到公众号后台。也可以连接自己的 AI 服务，获取文章建议、排版方案和封面配图。

**[打开楷排](https://kaipai.itskairo.com/)** · 无需注册或登录

## 可以做什么

- **编辑与导入**：直接编辑文章，导入 Markdown、纯文本、HTML 和 Word（`.docx`）文稿。
- **切换文章风格**：提供 12 套排版风格，支持字号、行高、留白和强调色等微调，也可以保存自己的风格偏好。
- **组织正文内容**：插入引用、重点卡片、提醒、分割线、代码、表格和图片，在右侧查看公众号排版预览。
- **检查文章与 AI 排版**：连接自己的文字模型后，获取可逐条处理的文章建议，或生成全文排版方案，确认后再应用。
- **制作封面与配图**：连接相应模型后，制作有字或无字封面，为当前段落或整篇文章构思、生成配图。
- **保存与导出**：文章和排版设置默认保存在当前浏览器，支持多文稿管理、复制公众号正文、导出 HTML 和 Markdown，以及下载文章图片包。

## 怎么使用

1. 打开网站，导入文稿或直接粘贴正文。
2. 选择文章风格，调整文字、组件与图片。
3. 根据需要配置自己的 AI 服务，检查文章、整理排版或制作图片。
4. 检查右侧预览，复制正文到公众号后台，再核对手机预览。

基础编辑与排版无需配置 AI。AI 功能需要自行提供供应商 API Key，并由对应供应商计费；云端模型请求经楷排服务端转发，本机回环模型由浏览器直连，需允许浏览器访问本机服务。Skill 准备和审核仍使用楷排服务端。

## 使用前了解

文章和素材记录默认保存在你当前使用的浏览器中，不会自动同步到其他设备，清理浏览器数据前请先导出备份。

楷排目前没有接通公众号账号授权和自动发布。复制保留原图片地址，不会自动把本地图片上传到微信；可下载文章图片包，在公众号后台补齐。复制完成后仍需在公众号后台检查效果。
