# 2026-10-30 楷排代码排查与修复

范围：当前生产实现 app/、lib/，API 路由、文稿和图片存储、排版转换、编辑器与页面集成、Cloudflare 缓存及 GitHub 发布链路。纳入用户确认的手机端布局和更多操作菜单。archive/legacy/、独立试验插件及无关设计稿不在本次发布范围。

## 修复

- 首次自动保存保留编辑器实例，保持光标和撤销历史。原版浏览器实测同一编辑器节点消失、失焦、撤销不可用；修复后 Next 与 Workers 两种构建均通过。
- HTML 不再转换成无结构纯文本，保留编辑器支持的标题、加粗、链接、表格和图片。Word 内嵌图片允许作为文稿图片导入。已验证刷新恢复及导出内容。
- 文稿删除失败时保留最新恢复记录，避免只删备份却提示成功，随后重新出现旧稿。数据库不可读时提示失败供重试；只有确认无旧记录才清理独立备份。
- 素材库保存失败保留输入；图片读取失败显示提示并结束异步任务。
- 本机 API 的模型目录、图片 JSON、图片下载和服务识别按实际读取字节限制，防止完整加载过大响应后才报错。保持现有认证、取消与不重试付费请求的行为。
- 本机地址提前展示浏览器授权说明，监听授权变化；拒绝授权时使用中性引导，避免无关参考模型请求。公网地址不展示本机权限提示。真实浏览器权限仍由用户决定。
- 手机菜单贴近触发按钮、支持外部点击和 Escape 收起；恢复桌面帮助按钮的紧凑显示。320、390、768 像素宽度无整页横向溢出。
- 纯文本复制保留段落、换行和表格单元格分隔；删除图片包中已过时的自动转存说明。

## 验证

完整 npm test、TypeScript、Next.js 生产构建、Cloudflare 构建及产物门禁、CSS 重复声明检查。Workers 实际 HTTP 验证覆盖凭据封装、跨站拒绝、日志与错误脱敏、重定向、流式回复完整性和限流；使用合成凭据及本机模拟接口。

浏览器验收覆盖首次保存、HTML/Word 导入、文稿恢复、排版切换、导出、手机菜单、素材库保存失败和权限状态变化。权限交互分支使用仅测试页的模拟状态，未修改真实浏览器权限。实际正式域名曾观察到 loopback-network=denied，未将其作为网站代码可自动解除的问题。

首页缓存 HIT、查询参数与 Cookie 绕过、API 不缓存，以及编辑器预加载在样式之后且只插入一次，均通过 Workers 本机运行时检查。历史资源按原路径和 SHA-256 保留。

详细日志和截图位于 docs/validation/full-audit-20261030/。这次是对当前实现的系统排查与回归，不代表能够证明不存在任何缺陷；未调用用户真实付费模型，也不代表正式域名网络线路性能已改善。发布结果以 GitHub Actions 和两个入口的 /api/release 为准。
