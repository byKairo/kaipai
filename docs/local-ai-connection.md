# 在公网楷排使用本机 API

1. 保持自己的本地 API 服务运行，打开公网楷排。
2. 填写服务的实际地址（例如 `http://127.0.0.1:8317/v1`）和 API Key，点击识别模型。
3. 浏览器首次询问本地网络访问时，选择允许。
4. 选择文章、封面模型，按需测试，再保存。下次打开页面可恢复配置。

无需启动楷排连接程序，也不需要 3003 端口。支持 OpenAI 兼容的模型目录、聊天、Responses、图片生成及 Gemini 图片聊天协议。你的 API 本身需要允许楷排网站跨域访问；浏览器禁止本地网络访问或服务未开放跨域时，网页不能绕过限制，会提示检查这两项。

本机 API Key 由当前浏览器加密保存，仅向所填本机地址发送；生成图片链接下载不会携带 Key。文章与画面要求仍可能发送到楷排服务端编译 Skill 提示词，图片审核结果也在服务端校验。清除网站数据后需要重新填写 Key。旧连接程序加密的 Key 需要重新输入并保存一次。

测试实际调用所选模型，保存不产生模型调用。模型目录识别失败可用参考目录或手动填写，参考型号不保证当前服务可用。

## CLIProxyAPI 浏览器连接兼容

楷排会无密钥识别回环服务。识别到 CLIProxyAPI 后使用官方支持的 X-Api-Key；普通服务继续使用 Authorization Bearer。不会将本机 Key 发送到网站服务端，也不会将 Key 放进 URL。失败的模型请求不会换认证方式自动再调用。

本机请求会声明浏览器回环地址空间。若浏览器明确禁止该网站访问本机网络，需要用户在网站权限中允许；网页不会绕过此限制。
